# 🔐 AI Secure Data Intelligence Platform

## 🚀 Overview

This project is an AI-powered platform that analyzes log files to detect sensitive data leaks and security vulnerabilities.

## 🎯 Problem

Log files often contain sensitive information like passwords, API keys, and system errors, which can lead to security breaches.

## 💡 Solution

This system:

* Detects sensitive data (passwords, API keys, emails)
* Classifies risk levels
* Generates AI-based insights
* Masks confidential data

## 🧠 Features

* 🔍 Log file analysis
* 🔐 Data masking
* ⚠ Risk scoring
* 💡 AI insights
* 🛡 Security status

## 🛠 Tech Stack

* React.js (Frontend)
* FastAPI (Backend)
* Python (Processing)

## ⚙️ Setup Instructions

### Backend

cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m uvicorn main:app --reload

### Frontend

cd frontend
npm install
npm start
